# City-Walk
它把现实世界的“City Walk / 户外出行”和经典的“圈地/涂色”（类似 Splatoon 或 Agar.io 圈地版）完美结合了起来。  我们可以叫它“现实版电子足迹圈地战”或者“城市涂色大作战”。
# 城市染色 Demo
一个单机 Web 原型，用真实地图验证“走过格子、染成自己的颜色、抢回对手领地”的核心手感。
## 当前功能
- 真实地图底图：OpenStreetMap + Leaflet
- 本地格子系统：50m / 80m / 120m 可切换
- 个人足迹层：永久记录走过格子
- 赛季领地层：本地可抢占
- 模拟移动：点击地图、方向键、自动模拟
- GPS 测试：点击后定位到设备真实位置，误差 100m 以内才染色计入路线
- 本地对手：生成红/金/蓝队领地后可抢回
- 本地存档：数据保存在浏览器 `localStorage`
- 导出存档：下载 JSON 文件
- 全部重置：点击后立刻清空自己的颜色格子、路线、对手颜色格子和统计
- 面板收起：操作面板可一键收起，需要时再打开
## 说明
- 这个版本没有后端、登录、真实多人同步和服务器反作弊。它的目标是尽快测试核心体验：真实地图上的格子是否好玩、格子大小是否舒服、抢地反馈是否成立。
